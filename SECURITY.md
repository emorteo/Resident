# Security Policy

## Supported Version

The current public baseline is v0.9.42.

## Sensitive Data

RESIDENT may be used with wildlife photo-identification catalogues, field survey dates, site labels, and individual identifiers. These can be sensitive. Do not publish private catalogues, unpublished encounter histories, exact sensitive locations, or personal data in issues, pull requests, examples, or test fixtures.

## Reporting Security or Privacy Issues

If you find a privacy or security issue, please contact the repository maintainer through GitHub without attaching sensitive data publicly. Use synthetic examples when possible.
