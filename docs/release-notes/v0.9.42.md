# RESIDENT v0.9.42 Release Notes

v0.9.42 is the public baseline release prepared from the architectural hardening work.

## Highlights

- Standalone R pipeline.
- Runtime active-implementation guard.
- Duplicate-function reporting for historical override layers.
- TMB alias synchronization check.
- Public documentation and MIT license.
- Public smoke test using synthetic temporary data.

## Scientific Limitations

Some abundance model families remain diagnostic or simplified rather than full Program MARK-equivalent likelihood implementations. The interface intentionally labels these outputs to reduce overinterpretation.
